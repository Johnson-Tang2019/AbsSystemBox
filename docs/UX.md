# M1–M2 界面与验收

## 外观与交互

- 粉色主题：浅色为淡粉底与莓粉强调色，深色为梅紫灰底与浅粉强调色。
- Windows Desktop Acrylic 毛玻璃背景、半透明卡片、细边框、圆角和平面布局，不使用网页 UI。
- 支持浅色、深色、跟随系统；系统关闭透明效果、窗口失焦或不支持特效时可能采用系统回退背景。
- NavigationView 的五个主要入口：概览、内存、文件搜索、磁盘空间、规则；底部为诊断和设置。
- 窄窗口自动折叠导航；概览卡片根据实际内容宽度横排/竖排；正文换行，页面可滚动。
- 未实现能力明确显示“尚未实现”。真实数据接入前不展示 0%、0 GiB 或虚构硬件统计。
- 概览与内存页使用同一 OperationStatus 控件显示加载、取消和未就绪状态。
- Debug --demo 显示持续警示；普通模式及 Release 不生成示例系统读数。
- 当前主题只保留到应用退出，不创建用户配置；关闭窗口即结束进程。

## M1 历史验证

使用 Windows 原生 UI Automation 的 SelectionItem、Invoke 和 ComboBox 模式操作实际应用，
不是仅调用 ViewModel 或直接修改控件值。脚本：`scripts/ui-smoke.ps1`。

1. 三轮切换七个页面，检查实际页面标题。
2. 在设置页选择浅色、深色及跟随系统，检查页面 ActualTheme 标签。
3. 普通 Debug 和 Release：刷新显示明确未就绪状态，没有模拟指标。
4. Debug --demo：实际触发加载、取消、导航离开时取消、回到新页面再读取示例数据。
5. Release 携带 --demo：仍不启用示例模式。
6. 缩至 900 × 740 物理像素，页面仍可导航与滚动。
7. 关闭窗口后进程以 0 退出，无本次启动的窗口残留。

运行证据写入 `artifacts/ui/<配置>-<模式>/report.json` 和窗口 PNG。
README 截图来自正常 Debug 模式，未展示模拟数据。

## M2 只读内存界面

内存页沿用粉色毛玻璃和扁平卡片：上方提供自动刷新/停止、立即刷新和取消当前读取，
中间显示物理使用率、已用/总量、可用量和提交量/限制；下面为最多 60 点历史曲线和进程表。
页面进入后采样，离开/关闭即取消循环；停止自动刷新会保留最近数据以供查看，也可手动更新。
每个窗口对七个固定页面各复用一个视图，保持固定的 ViewModel 绑定；内存页离开时清空列表/历史并停止任务。
进程表按工作集降序显示前 200 项，名称/PID/工作集/私有提交/启动时间分别展示，
完整路径只在悬停提示中出现；窄窗口的表格可横向滚动，列表固定高度并虚拟化。
没有清理、结束进程、调试权限开关或“可释放内存”宣传。

概览页进入时读取一次真实状态，内存详情页持续采样。
Debug --demo 同时替换概览、系统内存和进程采集器，避免在同一示例窗口混用真实数据与假数据。
Release 不包含这些模拟实现。测试脚本现在验证真实计数、自动刷新、停止冻结、手动读取及进程表，
记录中新增进程令牌权限、独立 OS/CIM 参考值和可选资源观察。

本次最终会话的 PrintWindow 图像缺失 DirectComposition 客户区，未作为视觉验收或仓库截图使用。
实际启动、导航、主题状态、内存/进程单元格、停止/取消通过原生 UI Automation 验证；最终像素级截图仍待可捕获桌面复核。

`-StandardUser` 通过桌面 Shell 启动并断言令牌未提升；UAC 关闭的机器会明确失败。
本机因此使用 `-RestrictedUser` 从已提升的验证宿主创建受限子进程，检查管理员组不可用，
不更改 UAC/账户设置。该辅助启动器位于 tests/Windows，不属于产品。
`-StabilityCycles 30 -MonitoringSeconds 90` 可记录短时持续采样和页面循环的资源变化，
不会调用强制 GC 或调整工作集。M2 报告保存在 docs/validation/m2/，详细解释见 MEMORY.md。

## M3 规则与充电卡片

规则页沿用粉色毛玻璃 SurfaceStyle，包含有效规则摘要、实时观察/通知、完整 YAML TextBox、修改原因、
字段错误与模拟时间序列、提案审批和版本选择。对话框提供完整旧/新配置、哈希、基准版本与模拟结果，默认取消。
危险动作始终不可启用，批准仅更新通知规则，不触发内存清理。
概览和内存页仅在 Windows 报告正在充电时显示净充电功率和估算时间；未知字段给出不可用提示。
诊断页区分无电池和报告不可用。Debug 明确示例预览可验证 45 W/60 分钟，不能当作真实笔记本硬件验收。
M3 实际原生 UI Automation 流程通过；现有 PrintWindow 的 DirectComposition 像素捕获限制保留，未声称完成最终截图、高 DPI 或多屏验收。
