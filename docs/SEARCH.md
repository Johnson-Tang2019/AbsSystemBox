# 文件搜索（M5）

仅查询用户手动建立的 SQLite 元数据索引，不依赖 Everything，不读取内容或记录查询历史。界面有 180 ms 输入防抖，新输入取消旧查询，离开页面使迟到结果失效。查询在后台执行；单一 ViewModel 不重叠运行查询。

语法：普通空格分隔名称条件为 AND，双引号表示含空格的连续短语。支持 `*.pt`、`ext:onnx`、`path:"D:\Folder Space"`、`type:file` / `type:folder`、`size:>1GB`、`modified:>=2026-01-01`。大小单位 B/KB/MB/GB/TB 均按 1024 进制；日期按 UTC 零点；比较符为 =、<、<=、>、>=。path 为完整目录及其后代范围，不是任意路径子串。未知字段、未闭合引号、非法日期/单位/通配、超大值都明确拒绝。

解析器生成 AST，再转换为仅包含允许字段/操作符的 SQL，值全部参数化。`%`、`_`、单引号等普通名称字符按字面匹配。最多 2048 个字符、32 个条件，单页 1–200 条，界面固定 100 条且换页替换集合，不累计所有结果。空查询不枚举数据库。默认隐藏项不显示，可勾选包含。重叠范围按精确路径去重，不合并仅大小写不同的路径。

排序包括完整/前缀/子串相关性、路径、逻辑大小降序、修改时间降序；未知大小/日期排最后。offset 最大 100000，后续页须携带第一页的活动 generation 摘要；重扫或清缓存导致摘要变化会返回 INDEX_CHANGED，避免混用两代结果。一个查询内以 SQLite 读事务固定快照。读取只读连接，不接受外部 SQL。

SQLite progress handler 每 1000 条虚拟机指令检查取消/两秒合作预算，超限明确提示缩小范围，不把截断结果当成成功。连接锁等待另有两秒上限；同步文件系统/连接操作不保证被立即打断。1–2 字符按名称子串有限时扫描，并明确提示性能边界。FTS5 trigram 仅在隔离实验数据库比较，不作为生产查询依赖；实测见 validation/m5/query-experiment.json。小于三个 Unicode 字符的 trigram MATCH 不匹配，故不能直接替换中文短查询。

原生虚拟列表显示名称/路径/类型/逻辑字节/日期/完整度，状态区区分未建索引、无结果、语法错误与部分覆盖。索引是扫描快照，不保证文件仍存在。复制路径、资源管理器定位和打开位于本机 UI；打开（含双击）先确认，默认取消，避免从结果静默运行可执行文件。定位用 shell PIDL/SafeHandle，不拼接命令行。打开前检查文件/目录仍存在，Shell 打开失败给出中文提示。

Debug/Release 各 140 项测试通过，包括中文/空格/同名文件、字面注入文本、类型/大小/日期/范围、重叠去重、分页与重扫冲突、防抖取消/迟到结果。受限非管理员真实窗口在 10051 个样本文件上验证扫描、分页、虚拟列表、错误/无结果、连续输入、中文、打开确认取消、导航与退出。没有调用用户数据或全盘扫描。未把确认取消等同于所有文件关联程序的实际启动验收，也未改动用户剪贴板来测试复制。独立机器、大规模索引及长时资源仍待验收。
