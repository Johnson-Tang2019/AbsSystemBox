# 安全边界

M2 增加只读内存统计与进程内存元数据，不扫描用户文件或读取进程正文，
不写用户配置，不提供管理员服务、IPC、网络监听或系统优化动作。
诊断页读取应用版本、OS/.NET 版本、进程架构及当前窗口缩放，不导出诊断包。
开发构建访问 NuGet 下载依赖；本项目没有网络请求或网页控件。
Windows App SDK 及 .NET 各自的条款见第三方声明。

默认客户端读取真实系统状态。模拟客户端只在 Debug 编译并需显式 --demo，
整个窗口显示模拟警示；Release 忽略该参数。页面取消和导航用请求代数隔离迟到结果。
界面测试脚本仅启动/操作/截取本应用窗口，不更改系统主题、显示缩放或用户文件。
产品清单明确 asInvoker、uiAccess=false。进程查询仅请求 QUERY_LIMITED_INFORMATION，
不启用 SeDebugPrivilege、不申请 VM_READ，也没有内存清理、终止进程或管理员代理接口。
完整路径只用于当前页面提示，不默认写日志或导出；提交到仓库的运行记录只有汇总指标。

本机 UAC 设置为关闭；从桌面启动仍会继承管理员令牌，所以不把这一点当作普通账户验收。
验收脚本的 -RestrictedUser 仅为本次子进程创建禁用管理员 SID/特权的中等完整性受限令牌，
检查实际 isElevated=false、isAdministrator=false；没有修改系统 UAC、账户或桌面权限。
该测试不等于在另一台机器的独立标准用户账户验收。测试辅助代码不编译进产品。

未来实现默认只读；不默认上传文件名、查询、路径、日志或规则。
文件搜索和空间分析不包含删除操作。目录扫描必须限制范围并处理权限和重解析点。
内存规则默认只通知，危险动作必须经过独立的人类审批与审计。
特权服务可选，UI 不常驻管理员权限；禁止任意命令代理。

这些是设计约束，尚未经过运行时安全验收。
