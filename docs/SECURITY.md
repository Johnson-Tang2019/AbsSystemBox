# 安全边界

内存监控不读取进程正文，文件扫描只在明确选择的目录进行，不跟随重解析点。
当前增加用户态 CoreHost、本地用户管道、CLI/MCP 与默认关闭的工作集清理，可选只读管理员服务已新增但默认不安装；没有 TCP/HTTP 监听。
诊断可导出脱敏版本/权限/资源计数，需用户选择保存位置，不包含索引路径、进程列表或规则正文。
开发构建访问 NuGet 下载依赖；本项目没有网络请求或网页控件。
Windows App SDK 及 .NET 各自的条款见第三方声明。

默认客户端读取真实系统状态。模拟客户端只在 Debug 编译并需显式 --demo，
整个窗口显示模拟警示；Release 忽略该参数。页面取消和导航用请求代数隔离迟到结果。
界面测试脚本仅启动/操作/截取本应用窗口，不更改系统主题、显示缩放或用户文件。
产品清单明确 asInvoker、uiAccess=false。进程查询仅请求 QUERY_LIMITED_INFORMATION，
不启用 SeDebugPrivilege、不申请 VM_READ，没有终止进程或管理员代理接口。
用户新增授权的工作集清理另外请求 SET_QUOTA，并严格检查目标用户、会话、提升权限和前台保护，见 CLEANUP.md。
完整路径只用于当前页面提示，不默认写日志或导出；提交到仓库的运行记录只有汇总指标。

本机 UAC 设置为关闭；从桌面启动仍会继承管理员令牌，所以不把这一点当作普通账户验收。
验收脚本的 -RestrictedUser 仅为本次子进程创建禁用管理员 SID/特权的中等完整性受限令牌，
检查实际 isElevated=false、isAdministrator=false；没有修改系统 UAC、账户或桌面权限。
该测试不等于在另一台机器的独立标准用户账户验收。测试辅助代码不编译进产品。

未来实现默认只读；不默认上传文件名、查询、路径、日志或规则。
文件搜索和空间分析不包含删除操作。目录扫描必须限制范围并处理权限和重解析点。
内存规则默认只通知，危险动作必须经过独立的人类审批与审计。
特权服务可选，UI 不常驻管理员权限；禁止任意命令代理。

既有验收和本次新增边界分别记录于 validation；未覆盖的独立用户/机器等场景不标记通过。

## 用户态管道与自动清理

管道显式仅允许当前用户 SID、拒绝网络 SID；只接受本地管道，不把未知原生错误当成本地成功。
双向读取 OS 提供的对端 PID，最小查询权限核对 SID/会话/固定映像路径；不使用请求字段授权。
输入有帧长/深度/超时约束，业务方法白名单；没有任意命令、任意 SQL 或提升权限代理。
规则审批/回滚、清缓存、清理启用仅桌面来源可调用。MCP/CLI 的布尔确认不会授权。
固定映像检查不阻止同用户恶意代码修改二进制或自动操作 UI，不能作为对抗同用户攻击的完整隔离。

自动清理独立配置，默认关闭；白名单为空拒绝启用，示例模式拒绝配置，Agent-only 后台不会执行。
当前桌面通信租约、原生同用户/同会话/非提升令牌/前台及身份复核全部满足后，才能处理普通后台进程。
运行前持久化限流记录，单轮最多 2 项/每小时最多 6 轮；关闭设置与实际执行在同一锁内串行。
配置损坏或审计不可写停用，保留原件。没有清空系统缓存/Standby List 或关闭系统进程的代码。

## M3

规则是声明式受限 YAML。事件流大小/深度/节点限制先于对象构造；禁止别名、标签、重复字段、未知字段及脚本/命令动作。
只有 notify 可以启用，trim_working_set 必须禁用；保护、交互审批、dry-run 与审计安全字段不能通过配置关闭。
Agent 端口只有读取、校验、模拟、提案；UI 对话框绑定不可变提案与基准哈希，取消/拒绝不应用，过期和冲突拒绝。
本地有界审计与版本事务不等于防篡改账本，同用户恶意代码/文件篡改与 UI 自动化不由接口划分解决。
有效 YAML 与审批、版本一起原子替换，失败保留有效版本，损坏存储停止观察而不重置。
Debug 测试存储覆盖不编译到 Release，验收审批仅发生在隔离目录。详细边界见 RULES.md。

电池信息经已有开源 C#/WinRT 投影只读查询，无驱动、设备写入、厂商接口或电源策略修改；不采集电池设备 ID。
充满时间只是估算，未知速率或容量不生成假值。硬件数据和示例预览隔离，见 BATTERY.md。

## 可选 NTFS 服务

固定 LocalSystem 服务只暴露五种只读元数据方法。System/获准 SID 的显式 ACL、网络拒绝、Token/会话/映像/模拟身份和卷授权共同校验；客户端核对 SCM 运行 PID、服务账户、固定映像和保护 ACL。配置只能由独立管理员安装器写入，不通过 RPC 提权或修改授权。

假服务管道、真实未授权映像、SID/卷/方法拒绝及 Agent 布尔伪造已通过定向测试，见 validation/ntfs-service。尚未完成真实 SCM 生命周期及隔离卷验证，不声称独立安全审计或所有生产场景通过。服务默认不安装，普通模式继续可用。安装/更新/卸载保留失败回滚材料和未知文件，详见 NTFS.md。
