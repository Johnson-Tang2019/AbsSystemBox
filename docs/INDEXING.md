# 普通目录索引（M4）

2026-10-27。用户在文件搜索页选择或输入目录，点击“开始 / 重扫”才读取该范围的名称、属性、逻辑长度和修改时间。不读取正文，不启动全盘扫描，不自动监视变化；修改/移动/删除后需手动重扫。

`DirectoryWalkIndexer` 在后台线程以显式枚举栈遍历，每层只保留一个枚举器。默认不跟随重解析点；根目录及祖先也是重解析点时拒绝。排除自身缓存目录，并允许调用方指定最多 256 个排除目录。默认最多 100 万条目、512 层，达到限制不发布不完整的新快照。取消在条目之间检查；暂停在批次提交后等待，不持有写事务。不能强行打断正在进行的同步文件系统调用。并发恶意替换目录与 junction 的竞态尚未用基于目录句柄的遍历消除，不把它作为安全隔离边界。

缓存位于 `%LOCALAPPDATA%\SysBox\index\metadata.db`。Debug 可用 `SYSBOX_TEST_INDEX_DIRECTORY` 隔离验收，Release 不编译此入口。SQLite WAL，连接均启用外键，2 秒锁等待；应用内信号量及独占 writer.lock 保证单一写者。跨进程锁被占用时返回错误，不排队占满线程。

Migration 1 使用 volumes、file_objects、directory_entries、index_state。此阶段 volumes 行实际代表用户选定的**目录范围**，SHA-256 标识来自规范化路径，identity_kind=directory-path；不伪称物理卷 GUID。FileId/ParentFileId 与分配大小均为空。目录项以大小写敏感的完整路径唯一，文件对象暂按目录项建立，硬链接逻辑字节重复计入，不能当作物理占用。后续 M6 接入真实卷/文件身份须独立迁移，不能把盘符或路径哈希当 NTFS 身份。

每 256 条提交暂存 generation，搜索读取仅加入 active_generation。完整或部分覆盖扫描结束后，在同一事务切换活动版本并移除旧快照；取消、失败、超过条目限制保持旧版本。上次未发布的暂存记录在下次扫描时清理。上次已发布报告和最近扫描报告分别保存，取消报告不冒充旧快照的完整度。一次最多 256 个范围；重叠目录可能重复出现，查询层应按路径去重。

访问拒绝、I/O/消失、跳过链接、排除项分别计数；Partial 指存在这些覆盖缺口，无法计算未知子树内的文件总数，故不报告虚假的覆盖百分比。界面预览最多 100 条，接口最多 1000 条。缓存范围列表最多 256 条。无实时变更承诺，文件打开前必须重新检查存在性。

清缓存需本机界面确认，只在事务中删除索引表记录，然后 checkpoint/VACUUM 回收数据库空间，不删除目录树、用户文件或规则。完成后可重新索引。安装升级同样保留缓存和规则。

验证：Debug/Release 各 115 项测试通过。新增真实样本对账、中文空格路径、大小/移动后重扫、取消/限制保留活动版本、暂停恢复、junction 循环、长路径、600 文件批次、多范围、独占写者及中断暂存恢复测试。真实 WinUI 以受限非管理员令牌通过隔离扫描、重扫、清缓存确认和正常退出；见 validation/m4。尚未验证真实 exFAT 设备、断开移动卷、网络超时、百万规模和独立标准账户。
