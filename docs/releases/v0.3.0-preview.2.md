# AbsSystemBox 0.3.0-preview.2

- 包含 0.3 界面修正：删除概览宣传/手动刷新区块，自动显示真实索引与容量；内存列表支持工作集/私有提交排序；电池显示健康度或“无”。
- 修正粉色悬浮球文字裁切与窗口边框，支持贴边收起、悬停展开、单击请求清理与双击主窗口。
- 内存页自动清理改为默认保护与可选排除名单，不再要求填写进程白名单。旧白名单配置保留旧范围，只有保存并重新确认后才迁移。
- 九类系统清理每次单独管理员确认；增加 Fluent Reduct 默认和 PCL 七项操作组合，组合按钮只选择、不执行。
- 磁盘摘要、列表、进度和面积图提示自动使用 GB/MB/KB/B，保留逻辑/已分配大小和部分覆盖语义。

Windows 11 x64 自包含预览安装包，支持覆盖升级并保留配置，未签名。Fluent Reduct 许可及来源随包保留，PCL 只参考操作组合，无上游程序运行依赖。

只运行新增定向测试和本轮新界面流程，复用既有验收。系统缓存/Standby 未在自动测试中实际执行，Windows 不支持的清理项会按项显示失败；NTFS 真实卷与服务生命周期验收仍按此前决定暂缓。
