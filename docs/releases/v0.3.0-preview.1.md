# AbsSystemBox 0.3.0-preview.1

- 简化概览与内存页面，删除宣传和手动刷新区块，概览自动显示实际索引/卷容量。
- 进程列表可按工作集或私有提交排序，后台从全部可读样本中取对应前 200 项。
- 内存页集成清理：默认关闭的阈值/定期进程清理，以及参考 Fluent Reduct 的九类系统内存清理。九类操作每次都要独立管理员确认，主窗口保持普通用户身份。
- 修复悬浮窗外框与文字裁切，保留粉色主题；新增进度环、贴边收起/悬停展开、单击请求清理及双击主窗口。
- 电池报告显示容量健康度，无电池显示“无”。

六项新增测试、非管理员真实窗口新流程、64 DIP 悬浮窗尺寸/文字边界与 helper 拒绝测试通过；旧业务验收记录沿用。系统缓存/Standby 未在自动测试中实际执行，原生不支持的项目会按项报告 NTSTATUS，不能保证每种 Windows 版本的每项操作均成功。真实 NTFS 卷/服务生命周期等此前未验收边界继续保留。

Windows 11 x64 自包含预览安装包，支持直接覆盖升级并保留配置，未签名。Fluent Reduct GPL-3.0-or-later 来源/许可随包保留，无 Electron 或上游程序运行依赖。
