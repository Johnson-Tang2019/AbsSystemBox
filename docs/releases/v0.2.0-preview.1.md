# AbsSystemBox 0.2.0-preview.1

Windows 11 x64 原生 WinUI 3 预览版，粉色半透明毛玻璃主题，支持直接覆盖已有 preview.1 安装并保留用户配置。

- 新增内存悬浮球、快捷搜索窗、热键、面包屑和真实卷容量。
- 普通目录索引、搜索与磁盘空间分析共享持久快照。
- 独立用户态 CoreHost、CLI 和官方 SDK MCP stdio；Agent 可只读、模拟与提案，不能自行审批。
- 阈值/定期工作集清理默认关闭，需桌面确认和进程白名单，包含前台/系统保护、冷却与审计。规则默认只通知。
- 新增可选只读 NTFS 服务与 MFT/USN 增量协调代码：改名/子树移动/大小/硬链接、祖先汇总、实体分配量去重、Journal 缺口重建提示和事务恢复。
- 服务默认不安装，卷默认不选择。独立管理员工具显示 SID/卷授权确认；安装不会扫描。服务缺失时普通目录模式仍可用。
- 统一版本与固定安装身份；程序与可选服务分别保留更新回滚材料，用户数据不随覆盖升级清除。

本轮新增 16 项 NTFS/安全定向测试及非管理员真实设置页流程通过，Debug/Release 构建通过。增量同步中断后搜索和磁盘页明确显示历史/部分数据。此前通过的测试复用已有记录，没有重复运行。

本预览版未签名。真实隔离 NTFS 卷对账、LocalSystem 服务安装/升级/移除及长期大卷性能尚未验收；NTFS 代码集成不等于生产环境认证。用户暂缓的整卷验证未执行。重启、其他系统、干净机器等验收不作为本轮通过项。具体范围见随包文档与仓库 docs/NTFS.md、docs/STATUS.md。

当前发布是功能预览，不宣称所有环境下的 1.0 正式验收完成。
