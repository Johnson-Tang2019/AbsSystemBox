# AbsSystemBox 0.2.0-preview.2

Windows 11 x64 原生粉色毛玻璃工具箱，支持直接覆盖已有版本并保留用户配置。

- 使用用户提供的粉色玻璃工具箱作为软件图标，外部白底改为真实透明，保留工具箱及内部白色高光。
- 同步应用 EXE、窗口、托盘、开始菜单、安装器与卸载器的图标，提供多尺寸 ICO，安装结束通知 Shell 刷新图标。
- 包含完整普通目录索引/搜索/空间分析、悬浮球、快捷搜索、用户态 CoreHost、CLI/MCP、默认关闭的阈值/定期清理，以及可选只读 NTFS 服务与增量索引代码。
- 默认不安装特权服务、不选择整卷、不执行内存清理。NTFS 服务需要独立管理员与卷授权确认，安装服务不会扫描。

已有 16 项新增 NTFS/安全定向测试和非管理员真实设置页证据沿用，此次只验证新图标与安装包，不重复已验收业务测试。0.2.0-preview.1 作为未公开的中间草稿保留，本版为加入新图标的交付版本。

真实隔离 NTFS 卷对账、LocalSystem 服务安装/升级/移除和长期大卷性能尚未验收；暂缓的整卷验证未执行。重启、其他系统、干净机器等场景不冒充通过。本预览版未签名，不宣称所有生产环境均已验收。详细边界见 docs/NTFS.md 和 docs/STATUS.md。
