# AbsSystemBox 0.3.1

新增金河田水冷屏显示控制，可选择温度与风扇 RPM 来源，也可使用明确标记的手动显示值。默认优先选择唯一的 **Core Max** 与 **CPU Fan**，记住稳定设备/传感器标识。未知、失效或重名读数会明确报错，不用其他硬件读数替代。

可开启“随应用启动同步”，配合设置中的登录启动，在开机登录后自动恢复显示；切换页面或隐藏到托盘不会停止同步，点击停止或完全退出才结束。

CPU 与主板传感器由可选的受保护后台服务独立采集，不需要运行 GoldenFiled 或 HWiNFO。授权安装时会进行一次管理员及原生确认；主界面保持普通权限。服务只接受固定的温度/RPM读取，不提供风扇、泵速、超频或任意命令。需要已安装的 PawnIO 驱动，本安装包不静默安装驱动。

升级请先完全退出旧版，再运行安装器。用户规则、索引和设置与程序目录分离并保留；已有服务需要通过水冷页的安装/更新入口维护。首次开启后台采集后，请检测并确认屏幕与默认来源，再保存自动同步偏好。

验证复用已接受的 14 项水冷测试与用户实机反馈，本轮只增加自动同步/默认选择及持久服务安全测试。其他硬件、驱动缺失、NTFS 与高 DPI 等既有验收边界继续保留。附件为自包含 Windows x64 安装器、对应源码、文件清单及 SHA256SUMS；未购买代码签名证书，请核对仓库与摘要。
