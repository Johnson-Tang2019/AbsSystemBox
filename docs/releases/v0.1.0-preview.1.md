# AbsSystemBox 0.1.0-preview.1

Windows 11 x64 原生预览版，采用粉色毛玻璃界面。

- 真实只读内存监控、历史曲线和进程内存列表。
- 内存规则校验、历史模拟、提案、审批、冲突检测和版本回滚。默认仅通知，无实际内存清理。
- 笔记本充电时显示电池净充电功率和预计充满时间，未知数据明确提示不可用。
- 当前用户安装，无需管理员权限；支持直接覆盖升级、同版本修复，保留规则和审计记录。

下载 `AbsSystemBox-0.1.0-preview.1-win-x64-setup.exe` 安装。以后更新时先关闭应用，直接运行新安装包，无需先卸载。
程序会识别已有目录和版本，阻止低版本覆盖高版本；卸载保留用户规则配置。
安装包包含 .NET 和 Windows App SDK 运行组件，安装说明见仓库 docs/INSTALL.md。

附件同时提供对应源码 ZIP、manifest.json 和 SHA256SUMS.txt。项目原创源码采用 GPL-3.0-or-later，第三方组件保留独立许可。

本地 Debug/Release 各 107 项测试通过。受限非管理员身份实际验证了首次安装、运行、覆盖升级、修复、降级拦截及卸载。
已安装程序实际加载了规则观察与真实只读内存页面，升级/卸载保留规则及未知文件。

已知限制：安装包尚未签名，Windows 可能显示未知发布者提示，请核对官方仓库与 SHA-256。
本机无电池，真实充电笔记本的功率与时间估算仍需实机核验；高 DPI、多屏和干净机器场景尚未完成。
文件搜索、目录空间分析、CLI/MCP 和特权服务仍未实现。本版本不提供自动后台更新。
