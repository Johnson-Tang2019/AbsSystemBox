# 路线图

| 阶段 | 范围 | 当前状态 |
|---|---|---|
| M0 | 工程、契约、规范、构建测试 | 本次实现，详见 STATUS |
| M1 | WinUI 3 导航、主题、页面状态 | 已实现，本地构建/运行验收，边界见 STATUS/UX |
| M2 | 真实只读内存与进程采集 | 已实现，验证记录见 STATUS/MEMORY |
| M3 | 规则校验、模拟、提案、审批与版本回滚 | 已实现；默认仅通知，验证见 STATUS/RULES |
| M4 | 普通目录索引 | 已实现，隔离样本与非管理员窗口通过；边界见 INDEXING |
| M5 | 文件搜索 | 已实现；140 项回归及 10051 文件原生窗口验收，见 SEARCH |
| M6 | NTFS/USN 高速增量索引 | 解析、只读实验适配器、离线 generation/checkpoint 事务与回放已实现；链接协调、生产发布与隔离卷验收未完成，见 NTFS_LAB |
| M7 | 目录大小引擎 | 普通目录版已实现；USN 增量 delta 尚未实现，见 STORAGE |
| M8 | 磁盘页与快捷搜索 | 目录排行/逐层浏览/面积图、容量列表/面包屑、快捷窗/热键和悬浮球已实现；多屏/高对比等环境验收尚待完成 |
| M9 | 可选特权服务与安全 IPC | 用户态 CoreHost/管道/身份验证/托盘生命周期已实现；特权 NTFS 服务尚未实现 |
| M10 | CLI 与 MCP | CLI 和官方 SDK stdio 工具已实现并完成标准客户端协议调用；Codex 应用连接验收尚待完成 |
| M11 | 性能、安装、升级、卸载验收 | 已有预览安装/覆盖升级/修复/卸载；干净机器、签名、长期性能待验收 |

细项与验收标准以 SYSBOX_MASTER_PLAN.md 为规划依据，以 STATUS.md 为实现事实。
