# 预览安装器验收

Windows 11 x64，受限非管理员令牌。通过 scripts/installer-smoke.ps1 实际安装 preview.0、直接覆盖升级 preview.1、同版本修复、阻止降级并卸载。
两个已安装版本均用原生 UI Automation 验证窗口、诊断版本、规则观察与真实内存读数，退出 code 0。
现有用户规则内容逐字节保留；未知文件保留，旧版已归属废弃文件清除。报告不包含用户路径、机器名或进程明细。
preview.0 是本地升级夹具，不发布。正式预览附件从干净提交重新构建并记录精确 sourceRevision、文件与安装器 SHA-256。
这不等于干净机器、独立账户、跨多代升级、突然断电恢复或已签名安装器验收。
